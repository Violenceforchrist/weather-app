# Meteor Weather Dashboard

A responsive weather dashboard with a modern dark interface, live city search, saved searches, and current weather data powered by OpenWeatherMap.

## Features

- Search for weather by city
- View temperature, weather condition, pressure, humidity, visibility, sunrise, and sunset
- Four-day forecast display
- Recent city searches saved in the browser
- Responsive layout for desktop and mobile
- Newsletter email validation
- Secure backend API proxy for OpenWeatherMap

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- OpenWeatherMap API
